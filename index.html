Setup: Publish It (20 min)

  1. Save this file as index.html (that exact name).
  2. On GitHub, create a new public repository and upload index.html.
  3. Go to Settings → Pages. Under "Branch" choose main and / (root), then Save.
  4. Wait a minute or two. Your site appears at https://YOUR-USERNAME.github.io/REPO-NAME/
  5. Edit loop: change the file on GitHub (pencil icon) → Commit → wait ~1 min → refresh the site.

Tip: while learning, you can also double-click index.html on your computer to preview changes instantly, no upload needed.

Day 1: Text & Tags

HTML is built from tags. Most come in pairs: an opening tag and a closing tag with a /.

<h1>Big heading</h1>      (h1 to h6, biggest to smallest)
<p>A paragraph.</p>
<strong>bold</strong> <em>italic</em>
<br>                       (line break, no closing tag)
<ul><li>item</li></ul>    (bulleted list)

Day 2: Colors & Fonts

Styling is done with CSS, inside the <style> block at the top. Each rule is property: value;

color: #2563eb;            /* text color (hex, name, or rgb) */
background-color: tomato;
font-family: "Poppins", sans-serif;
font-size: 20px;
font-weight: 700;          /* bold */

I'm styled right on the tag with style="..." (inline CSS).

Task (30 min)
  • In :root at the top of the CSS, change --accent to a new hex color. The whole site updates.
  • Pick a Google Font, replace the <link> in the head, and update font-family in body.
  • Change the inline demo above to a different color and size.

Day 3: Adding & Editing Photos

Upload your photo to the same GitHub repo, then point to it with <img>.

<img src="photo.jpg" alt="Describe the photo" width="300">
  • src = the file name (must match exactly, including capitals and .jpg vs .jpeg)
  • alt = text for screen readers and broken images
  • width = size in pixels
Task (30 min)
  • Upload a photo to your repo and swap the src above to its file name.
  • Change width="300" to other numbers. Rewrite the alt text.
  • In the CSS, find .demo img and change border-radius: 10px to 50% for a circle (works best on a square photo).

Day 4: Links & Anchors

The <a> (anchor) tag makes links. Its href says where to go.

<a href="https://wikipedia.org">External link</a>
<a href="https://wikipedia.org" target="_blank">Opens in new tab</a>
<a href="mailto:you@email.com">Email me</a>
<a href="#day1">Jump to the element with id="day1"</a>

Day 5: Backgrounds

Three kinds: solid color, gradient, and image. All use the background properties in CSS.

background-color: #fde68a;
background: linear-gradient(90deg, pink, skyblue);
background-image: url("photo.jpg");
background-size: cover;   /* fill the box */

Day 6: Layout & Spacing

A <div> is an invisible box used to group things. Give it a class to style it in CSS (see .row and .box).

padding: 20px;   /* space INSIDE the box */
margin: 20px;    /* space OUTSIDE the box */
border: 2px solid black;
display: flex;   /* put children side by side */
